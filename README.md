# Biosync – Smart Alarm System for Elderly Support

## Overview
Biosync is an Arduino-based medication reminder system designed to assist elderly individuals in following scheduled medication routines.

## Hardware Components
- Arduino UNO
- Real-Time Clock (RTC) Module
- Buzzer

## Working Principle
The system uses an RTC module to track time and Arduino-based scheduling logic to activate reminders at predefined intervals.

## Applications
- Medication reminders for elderly individuals
- Home-based medication management
- Embedded healthcare assistance

## Technologies
Arduino, Embedded C/C++, RTC Module
